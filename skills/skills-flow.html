Matt Pocock Skills Flow

Standard flow: setup once per repo, then align → plan → build → maintain, with utility skills available anytime.

  • Phase
  • Setup
  • Align
  • Plan
  • Build
  • Maintain
  • Utility 
flowchart TD
  %% PHASE LABELS
  A0(["🚀 NEW REPO"]):::phase --> A["/setup-matt-pocock-skills
Run once per repo"]:::setup

  A --> B0(["📐 ALIGN"]):::phase

  B0 --> B["/grill-with-docs
Deep grilling, update CONTEXT.md + ADRs"]:::align
  B0 --> C["/zoom-out
Unfamiliar code? Get system context"]:::align
  B --> D{Design still fuzzy?}:::decision
  D -->|Yes| E["/prototype
Throwaway to test design"]:::align
  D -->|No| F0(["📋 PLAN"]):::phase
  E --> F0

  F0 --> F["/to-prd
Turn convo into PRD issue"]:::plan
  F --> G["/to-issues
Break PRD into vertical slice issues"]:::plan
  G --> H["/triage
Prioritize via triage state machine"]:::plan

  H --> I0(["🔨 BUILD"]):::phase

  I0 --> I["/tdd
Red–Green–Refactor loop"]:::build
  I --> J{Bug / breakage?}:::decision
  J -->|Yes| K["/diagnose
Reproduce → Minimize → Hypothesize → Fix → Regression"]:::build
  K --> I
  J -->|No| L0(["🔁 MAINTAIN"]):::phase

  L0 --> L["/improve-codebase-architecture
Run every few days to reduce entropy"]:::maintain
  L --> L0

  %% UTILITY
  U0(["⚡ ANYTIME UTILS"]):::phase
  U0 --> U1["/caveman
Compressed communication, save tokens"]:::util
  U0 --> U2["/handoff
Package session for another agent"]:::util
  U0 --> U3["/grill-me
Lighter planning interview"]:::util
  U0 --> U4["/write-a-skill
Author new skills"]:::util
